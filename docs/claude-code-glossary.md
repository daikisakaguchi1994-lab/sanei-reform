# Claude Code用語集

## クエリ

- 説明：Claudeへの「質問・命令・入力」のこと
- 例：「.envファイルを読んで」と入力する行為
- イメージ：コンビニの店員さんに「おにぎりどこですか？」と聞く行為

## マークダウン

- 説明：記号だけで書ける簡単な文章フォーマット
- 例：`**太字**` と書くと太字になる
- イメージ：絵文字みたいに記号で意味を伝える書き方

## $ARGUMENTS

- 説明：カスタムコマンドの「穴埋め欄」
- 例：`/考えて バグを直して` → `think バグを直して` に変換される
- イメージ：宅配便の伝票の「お届け先」欄

## フック

- 説明：Claudeがツールを使う前後に自動で走る追加処理
- 例：.envを読もうとしたら自動ブロックする番人
- イメージ：コンビニの万引き防止ゲート

## PreToolUse

- 説明：ツール実行「前」に発動するフック。処理をブロックできる
- 例：.envファイルへのアクセスを事前に止める
- イメージ：入口の警備員

## PostToolUse

- 説明：ツール実行「後」に発動するフック。ブロックは不可
- 例：ファイル編集後に自動フォーマットをかける
- イメージ：出口の清掃スタッフ

## PR（プルリクエスト）

- 説明：コードをメインブランチに入れていいか申請する仕組み
- 例：GitHubで「この変更を取り込んでください」と申請する
- イメージ：上司に「この企画書を採用してください」と提出する行為

## SDK

- 説明：ClaudeをコードからBot自動操縦できる仕組み
- 例：毎朝9時に自動でGitHubのコミットをNotionに記録させる
- イメージ：自動操縦パイロット

## MCP

- 説明：Claudeに道具を追加する拡張パック
- 例：PlaywrightでClaudeがブラウザを自動操作できるようになる
- イメージ：スマホのアプリをインストールする感覚

## ターミナル

- 説明：コンピュータへ文字で命令を入力する画面
- 例：`npm run dev` と入力してサーバーを起動する
- イメージ：コンピュータへの「指示書き窓口」

## カスタムコマンド

- 説明：自分だけのオリジナル魔法の呪文
- 例：`/考えて` → `think` が自動発動する
- イメージ：マクドナルドの「いつものやつ」で注文できる常連客

## Exit Code

- 説明：処理の結果をClaudeに伝える信号
- 例：0=正常・続行、2=ブロック
- イメージ：信号機の青（進め）と赤（止まれ）

## JSON

- 説明：データを整理して保存する箱の書き方ルール
- 例：`{"name": "Daiki", "city": "福岡"}`
- イメージ：名刺の情報を箱に詰めた形式

## 絶対パス

- 説明：ファイルの場所を最初から全部書いた住所
- 例：`C:\projects\uigen\.env`
- イメージ：「日本・福岡県・博多区・○○町1-1」と書く完全な住所

## 計画モード（プランニングモード）

- 説明：実行前にプロジェクト全体を広く調べて計画を立てるモード
- 例：Shift+Tab×2で起動。複数ファイルの変更前に使う
- イメージ：工事前に設計図を全部見渡す建築士

## 思考モード（シンキングモード）

- 説明：一つの問題をじっくり深く考えるモード
- 例：`ultrathink` で起動。難しいバグの原因分析に使う
- イメージ：試験問題を30分かけてじっくり解く受験生

## TypeScript

- 説明：JavaScriptに「型チェック機能」を追加したプログラミング言語
- 例：変数の種類を事前に決めることでミスを防ぐ
- イメージ：宅配便で「壊れ物注意」シールを貼って丁寧に扱う感覚

## Node.js

- 説明：JavaScriptをブラウザ外・PC上で動かすエンジン
- 例：`node -v` でバージョンを確認できる
- イメージ：車のエンジン。これがないと動かない

## npm

- 説明：Node.jsで使う部品を自動インストールするアプリストア
- 例：`npm install` で必要な部品を一括取得
- イメージ：スマホのApp Store

## Prisma

- 説明：データベースを簡単に操作できる便利ツール
- 例：SQLを書かずにデータの読み書きができる
- イメージ：Excelの関数みたいに、難しい命令を簡単に書ける道具
